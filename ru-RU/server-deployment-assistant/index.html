Подробности о проекте

Ассистент развертывания сервера — это серверное решение формата для приложений типа «Browser as a Service».

На текущий момент Ассистент не является полностью универсальным. Хотя, сейчас уже есть возможность настроить некоторые параметры через файл settings.xml, функционал ограничен. Но, несмотря на это вы уже сейчас можете создать свое приложение типа «Browser as a Service» основываясь только на коде существующего Ассистента, не меняя его код. Я рекомендую изменить файл settings.xml так, чтобы значения портов и местоположения кэша CefCharp были уникальными. Это позволит пользователю использовать сразу несколько решений на одном устройстве.

На данный момент Ассистент находится в состоянии активной разработки. Основной идеей является создание универсального приложения, при помощи которого любой разработчик сможет сделать свое WebView-like приложений. Это может быть полезно, например, для создания клиента WhatsApp.

Помогите развитию проекта — сообщайте о проблемах, предлагайте новые функции!
Так же стоит отметить, что конечная цель — создание общего сервера для фанатов устаревших мобильных систем. Это позволит возрадить системы, пусть и не на долго. Если вы знаете как это можно реализовать, то создайте дискуссию с описанием предложения

Ассистент развертывания сервера является открытым инструментом для разработчиков. Вы можете использовать его в любых целях, но только при соблюдении основных принципов:

  • Поставлять Ассистент или его модификацию платно запрещено. Вы все ещё можете монетизировать свое клиентское приложение как вы желаете.
    Например: вы создали приложение MyApp, которое использует Ассистент. Вы сделали MyApp платным. Доступ можно получить только заплатив 0.99$. Но, ваш модифицированный Ассистент не должен быть доступен только при покупке MyApp. Вам следует разместить его в открытом доступе.
  • Если ваше приложение использует Ассистент или его модификацию, то следует указать на странице "О приложении", что для работы используется конкретная версия Ассистента.
    Например: "Работает с помощью Ассистента развертывания сервера"
  • Вы не должны использовать название "Ассистент развертывания сервера" как основной элемент представления приложения. В том числе: включать его в название приложения; делать акцент на том, что приложение работает с помощью Ассистента и др.
Стоит отметить, что сама по себе монетизация приложения на Windows 10 Mobile бесполезна. Однако, никто не говорит, что клиентское приложение может быть только на устаревших ОС, так что правила про монетизацию не лишние :-)
