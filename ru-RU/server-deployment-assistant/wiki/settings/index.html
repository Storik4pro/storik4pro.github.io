Файл конфигурации

Файл конфигурации позволяет гибко настроить ваш Ассистент Развертывания Сервера для вашего приложения.

Группа параметров Ключ Тип Описание
AudioStreamSettings AudioStreamPort int Порт, на котором следует запустить сервер для передачи звука
UseAudioResampling bool Понижать ли частоту звука.
AudioStreamResamplingRate int Целевая частота звука для понижения.
UseAudioGzipCompress bool Использовать ли сжатие звука с помощью Gzip.
VideoStreamSettings VideoStreamPort int Порт, на котором следует запустить сервер WebSocket.
UseVideoGzipCompress bool Использовать ли сжатие видео с помощью Gzip.
ScalingFactor int Значение, на которое следует умножить ширину и высоту окна браузера.
FullPageScreenshotQuality int Качество скриншотов для статического режима и миниатюр вкладок
BrowserSettings UserAgent string Строка кастомного агента пользователя
FirstRunUrl string URL, который будет открыт при первом запуске браузера и при закрытии всех вкладок.
CachePath string Путь к папке, в которой будет храниться кэш браузера. Данный путь является относительным к папке, в которой находится окружение приложения.
SearchSystem string Поисковая система, которая будет использоватся в тех случаях, когда в качестве URL был передан не валидный адрес.

Если settings.xml отсутствует или его невозможно открыть, то будут использованы значения по умолчанию.
  • int — 0
  • float — 10.0
  • string — NaN
  • bool — false
  • Для других типов стандартными значениями являются стандартные для языка C# значения по умолчанию.

Если Server Deployment Assistant используется в качестве движка для другого серверного приложения, то файл конфигурации можно указать через параметр командной строки --set-xml-settings-file <path>
