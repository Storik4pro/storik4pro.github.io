Apply for => 1.2.7 and later

Настройка прокси

Краткое описание функции

Функция настройки прокси позволяет настроить компоненты, которые работают в режиме прокси (Например, byeDPI). В качестве вариантов настройки предлагается несколько вариантов настройки - ручная, для всей системы, для выбранных приложений.
Выбранный вариант запуска будет использоваться по умолчанию для всех компонентов, чей запуск происходит в режиме прокси.

Настройка для всей системы (TCP) ▼
Краткое описание функции

Вся система по умолчанию работает через ByeDPI / SpoofDPI
+ меньше задержка
- нельзя настроить гибкое проксирование для приложений
- нет поддержки UDP

Доступные настройки

  • Исключения
    В окне ввода адресов можно указать те адреса (привести разные примеры формата ввода адресов), которые проксировать не нужно и трафик к ним пойдет в обход ByeDPI / SpoofDPI. Разделять адреса следует с помощью символа ";"
  • Вкл\выкл проксирование для локакальных (внутресетевых) адресов
    Позволяет исключить из списка проксирования внутренние адреса, чтобы исключить проблемы с доступом к локальным ресурсам, маршрутизатору и т.д.
  • Настройки адреса для прокси
    IP адрес - указывается IP, на котором запущен прокси-сервер ByeDPI / SpoofDPI (по умолчанию используется 127.0.0.0)
    Порт - указывается порт, на котором запущен прокси-сервер ByeDPI / SpoofDPI (по умолчанию используется 1080)

Примечание

При выборе этого способа настройки будет проксироваться весь трафик с вашего ПК, что может привести к проблемам, если на ПК установлена не совместимая с компонентом программа. Например, ByeDPI может выдать ошибку add_event: pool is full
Программа не будет предварительно настраивать трафик для компонента-прокси, из-за чего настройка для UDP соединений может быть усложнена.
Изменяет системные настройки прокси в реесте по пути \HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Internet Settings
Изменяемые параметры: ProxyServer ProxyOverride ProxyEnable.

Приложение следит за статусом работы компонента и выключит проксирование трафика в системе при завершении работы компонента, чтобы избежать продолжительного отсутствия Интернет-соединения.

Краткое описание функции

С помощью Proxifyre перенаправляет трафик от выбранных приложений через прокси-сервер ByeDPI / SpoofDPI
+ позволяет выбирать приложения для проксирования
- увеличивает задержку

Доступные настройки

  • Список приложений, трафик которых будет проксироваться через ByeDPI / SpoofDPI
    1. Можно выбрать из предложенного списка установленных приложений
    2. Можно добавить вручную, нажав на кнопку "+ добавить приложение вручную"
    Жмем "Далее".

  • Тип трафика, который следует проксировать
    Оставить по умолчанию или выбрать на ваше усмотрение

  • Настройки адреса для прокси
    IP адрес - указывается IP, на котором запущен прокси-сервер ByeDPI / SpoofDPI (по умолчанию используется 127.0.0.0)
    Порт - указывается порт, на котором запущен прокси-сервер ByeDPI / SpoofDPI (по умолчанию используется 1080)

Примечание

Для выбора поддерживаются как классические Win32 приложения, так и приложения Universal Windows Platform. Для ручного добавления классического приложения достаточно указать имя исполняемого файла (Например, explorer). Для добавления UWP-приложения необходимо указать путь к его папке (Например, C:\Program Files\WindowsApps\Microsoft.BingWeather_4...).

Для начала настройки необходимо установить ProxiFyre и Windows Packet Filter. Сделать это можно через меню "Система"->"Компоненты" или в мастере настройки прокси. Перед началом установки необходимо принять стороннее лицензионное соглашение

Краткое описание функции

Этот пункт позволяет вручную задать адрес и порт, на котором будет запущен прокси сервер ByeDPI / SpoofDPI. Данный пункт имеет приоритет над параметрами, указанными в стратегии.

Например:
Если задана стратегия -i 192.168.1.2 -p 10880 -Ku -a1 -An -Kh,t -o1+s, то в ней указаны листинг IP и порт, на которых запустится прокси-сервер. Однако, если в пункте ручной настройки выставлены другие IP и порт, то прокси сервер будет запущен именно на них, несмотря на указанные в стратегии.
