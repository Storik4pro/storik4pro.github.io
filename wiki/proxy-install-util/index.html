Apply for => 1.2.7 and later

Настройка прокси

Краткое описание функции

Функция настройки прокси позволяет настроить компоненты, которые работают в режиме прокси (Например, byeDPI). В качестве вариантов настройки предлагается несколько вариантов настройки - ручная, для всей системы, для выбранных приложений.
Выбранный вариант запуска будет использоваться по умолчанию для всех компонентов, чей запуск происходит в режиме прокси.

Настройка для всей системы (TCP)

Краткое описание функции

При выборе этого способа настройки будет проксироваться весь трафик с вашего ПК, что может привести к проблемам, если на ПК установлена не совместимая с компонентом программа. Например, ByeDPI может выдать ошибку add_event: pool is full
Программа не будет предварительно настраивать трафик для компонента-прокси, из-за чего настройка для UDP соединений может быть усложнена.
Изменяет системные настройки прокси в реесте по пути \HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Internet Settings
Изменяемые параметры: ProxyServer ProxyOverride ProxyEnable.

Приложение следит за статусом работы компонента и выключит проксирование трафика в системе при завершении работы компонента.

Вы можете просмотреть текущие системные настройки прокси в приложении Параметры

Настройка для приложений (TCP+UDP)

Краткое описание функции

При выборе этого способа настройки вам будет предложено выбрать приложения, для которых трафик будет проксироваться. В утилите просмотра вывода процесса появится возможность показать вывод ProxiFyre. Можно выбрать тип трафика, который будет проксироваться (TCP и/или UDP).
Для выбора поддерживаются как классические Win32 приложения, так и приложения Universal Windows Platform. Для ручного добавления классического приложения достаточно указать имя исполняемого файла (Например, explorer). Для добавления UWP-приложения необходимо указать путь к его папке (Например, C:\Program Files\WindowsApps\Microsoft.BingWeather_4...).

Для начала настройки необходимо установить ProxiFyre и Windows Packet Filter. Сделать это можно через меню "Система"->"Компоненты" или в мастере настройки прокси. Перед началом установки необходимо принять стороннее лицензионное соглашение

Ручная настройка

Краткое описание функции

Позволяет выбрать параметры запуска компонента-прокси вручную. Дополнительные действия при запуске компонента предприниматься не будут.
