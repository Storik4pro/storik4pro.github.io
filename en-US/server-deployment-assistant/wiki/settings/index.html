Configuration File

The configuration file allows you to flexibly configure your Server Deployment Assistant for your application.

Parameter Group Key Type Description
AudioStreamSettings AudioStreamPort int The port on which the audio streaming server should run
UseAudioResampling bool Whether to downsample the audio
AudioStreamResamplingRate int The target sample rate for downsampling
UseAudioGzipCompress bool Whether to compress audio using Gzip
VideoStreamSettings VideoStreamPort int The port on which the WebSocket server should run
UseVideoGzipCompress bool Whether to compress video using Gzip
ScalingFactor int The factor by which to multiply the browser window width and height
FullPageScreenshotQuality int Screenshot quality for static mode and tab thumbnails
BrowserSettings UserAgent string Custom user-agent string
FirstRunUrl string The URL to open on first launch and when all tabs are closed
CachePath string The path to the folder where the browser cache will be stored (relative to the application directory)
SearchSystem string The search engine to use when an invalid URL is provided

If settings.xml is missing or cannot be opened, default values will be used:
  • int — 0
  • float — 10.0
  • string — NaN
  • bool — false
  • For other types, the language’s standard default values are used.

If the Server Deployment Assistant is used as the engine for another server application, you can specify the configuration file via the command-line parameter --set-xml-settings-file <path>
