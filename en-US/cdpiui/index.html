Project Details

CDPI UI — This is a modern and powerful tool for managing popular traffic modification tools (Zapret, ByeDPI, GoodbyeDPI, SpoofDPI).

What's changed?

GoodbyeDPI UI is now CDPI UI. Not only has the name changed, but the app has been rewritten from the ground up, reducing background RAM consumption to 8 MB, improving app stability, and making the GoodbyeDPI component optional. Furthermore, the app takes up only 135 MB of hard drive space1.

Components and presets are now available for download through the Store, a free platform for downloading components from the official repository. You can add your own elements to the Store or download existing ones.

Automatic launch parameter selection is now more stable and has a user-friendly interface for creating presets for multiple website lists at once.

You can now rename your presets and add them to the standard selector. You no longer have to add presets to the selector through roundabout methods or constantly select a new JSON file.

1 The final app size depends on the elements installed from the Store and the amount of personal user data.
