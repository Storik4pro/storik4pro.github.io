What do I need to do to start my journey on the Internet?

To start using Line Browser, follow these simple steps:
  • Download and install the server deployment assistant (hereafter “Assistant”) using this link
  • Add the Assistant to your firewall exceptions list; make sure nothing is blocking ports 8081 and 8082
  • Launch the Assistant and wait for the message confirming the port has been opened successfully
  • Download and install Line Browser via this link . If you have not installed apps on Windows 10 Mobile before, refer to the installation guide .
  • Ensure your phone and PC are connected to the same network
  • Specify the IPv4 address for connection in the format ws://IPv4-address:port
    Note: the address suggested by the Assistant may not always work. In that case, open your PC’s network settings and enter the current IP address manually.
  • Configure any other connection settings as desired and click “Connect.”
  • All set!
